## How a request flows

```text
Browser  ──HTTPS──▶  nginx :443      (Let's Encrypt cert)
                     │
            ┌────────┴────────┐
            ▼                 ▼
    static files         /api/*  ──▶  Spring Boot :8080  ──▶  MariaDB :3306
                                          │
                                          │ presign PUT (IAM role)
                                          ▼
                                  S3 (us-east-1)
                                  bucket: gotokart-product-images-…
                                          │
                                          ▼  GET (public read on products/*)
                                       <img src="…">
```

Bytes for product images **never traverse the JVM**. The backend signs short-lived PUT URLs; the browser uploads straight to S3.
